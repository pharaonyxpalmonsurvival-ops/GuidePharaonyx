01 — INTRODUCTION

Vue d'ensemble

Pharaonyx Bot est le compagnon officiel de la guilde Pharaonyx [PYX] sur Palmon Survival (Serveur 178). Il centralise la gestion des événements, des membres, des sondages, et bien plus — le tout en français et en anglais.

📅
Événements
Annonce boss, ruines, dirigeable et tempêtes. Agenda automatique avec timestamps Discord natifs.
📚
Encyclopédie Palmon
Fiches Palmon avec builds, compétences et conseils. Création guidée sans redémarrage.
📊
Sondages
Sondages interactifs (commun ou leader) avec timer natif, vote en temps réel et clôture auto.
🌐
Traduction Auto
Traduction FR↔EN automatique dans tous les chats. API MyMemory — 0 dépendance externe.
🎖️
Gestion des Rangs
Panneau de gestion des rangs R1→R5 avec logs dans #gestion. Permissions hiérarchiques.
⭐
XP & Classement
Système d'XP par message, anti-spam, level-up automatique et top 15 membres actifs.
🚫
Blacklist
Système de blacklist avec bannissements fondés ou supposés, logs complets.
↗️
Transferts
Transfert silencieux de messages — ciblé, par quantité, ou historique complet.

12 — COMMANDES

Transferts de messages

🔇 Entièrement silencieux Aucune notification envoyée à l'auteur du message original. La commande disparaît après utilisation. L'embed inclut l'auteur, la date d'origine et le salon source.

Comment utiliser /transfert

1 Clic droit sur le message cible
→
2 "Répondre" — envoie la réponse
→
3 Tape /transfert + salon
→
4 Confirmation éphémère ✅

17 — SYSTÈMES

Traduction automatique

Traduction automatique FR↔EN utilisant l'API MyMemory (gratuit, sans clé API, via urllib natif Python).

Salons concernés

La traduction est active dans tous les salons de chat : #leader-chat, #alliance, #chat-general, #nsfw, #chat-palmon, #chat-reproduction, #chat-ruines, #chat-sandstorm, #chat-dirigeable.

Fonctionnement

Détection de langueAnalyse des mots communs + caractères spéciaux FR. Fallback = français.
Limite journalière900 requêtes/jour. Au-delà, bouton manuel "🌐 Traduire" proposé.
Longueur max500 caractères par requête (tronqué si nécessaire).
Messages ignorésMessages de bots, liens seuls, textes < 5 caractères.

19 — SYSTÈMES

Agenda automatique

L'agenda est alimenté automatiquement par chaque commande d'événement. Il utilise les timestamps Discord natifs pour afficher les heures dans le fuseau local de chaque joueur.

Nettoyage automatique

Les événements passés depuis plus de 48 heures sont supprimés automatiquement toutes les heures. Le nettoyage est aussi déclenché à chaque appel de /agenda.

/agendaAffiche les prochains événements triés par date.
/agenda-add [type] [date] [heure]Ajoute manuellement un événement (boss, ruines, dirigeable, tempete).
/agenda-remove [type] [date]Supprime manuellement un événement.
20 — SYSTÈMES

Tirage Dirigeable

Le tirage du pilote garantit une rotation équitable — un joueur ne repasse pas tant que toute la liste n'a pas joué.

💡 Joueurs hors Discord La liste dirigeable stocke des pseudos textuels. Les membres n'ont pas besoin d'être sur Discord — utile pour les joueurs qui participent en jeu uniquement.

Algorithme de rotation

  1. Tirage aléatoire parmi les joueurs du cycle courant (non encore sélectionnés)
  2. Le joueur tiré est retiré du cycle courant
  3. Quand le cycle est vide → nouveau cycle avec tous les joueurs (sauf le dernier pilote)
  4. Animation d'élimination humoristique pour tous les non-sélectionnés
